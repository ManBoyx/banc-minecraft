# Banc et étal (modèles de blocs Minecraft)

Deux modèles de blocs Minecraft au format JSON :
- `banc.json` : un **banc en bois simple**, qui réutilise les textures vanilla `minecraft:block/oak_planks` et `minecraft:block/stripped_oak_log` ;
- `assets/banc/models/block/etal.json` : un **étal de vendeur villageois avec banc**, avec sa texture 32×32 `assets/banc/textures/block/etal.png`.

## Utilisation
Placez le dossier `assets/banc/` dans un pack de ressources ou un mod (espace de noms `banc`) : le modèle est alors `banc:block/etal`. Les fichiers JSON s'ouvrent aussi dans [Blockbench](https://www.blockbench.net) pour les modifier.

# English

# Bench and stall (Minecraft block models)

Two Minecraft block models in JSON format:
- `banc.json`: a **simple wooden bench**, reusing the vanilla textures `minecraft:block/oak_planks` and `minecraft:block/stripped_oak_log`;
- `assets/banc/models/block/etal.json`: a **villager vendor stall with a bench**, with its 32×32 texture `assets/banc/textures/block/etal.png`.

## Usage
Put the `assets/banc/` folder in a resource pack or a mod (namespace `banc`): the model is then `banc:block/etal`. The JSON files also open in [Blockbench](https://www.blockbench.net) for editing.
